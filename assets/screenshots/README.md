# 截图投放目录 / Screenshots

把截图丢进这个目录，**文件名按下面的清单来**——名字固定，我拿到后直接接线到两个 README 顶部和根目录的 `screenshots.json`（插件市场卡片的轮播图会自动读它，不用再提 PR）。

## 需要哪些

| 文件名 | 内容 | 优先级 |
| --- | --- | --- |
| `01-status.png` | 回合进行中，底部状态行是插件的**彩虹渐变 + 打字机**文案（能同时看到弹幕更好） | 必须 |
| `02-danmaku.png` | **弹幕**飘过聊天区，能看清 3–5 条不同颜色 / 字号的文案 | 必须 |
| `03-settings.png` | 设置 → **状态文案**页面（词库编辑区 + 基本设置） | 必须 |
| `04-packs.png` | **词库包**区域：`star-ask` / `star-route` 两个开关（默认关闭）+ 页面**最底部的仓库链接** | 必须 |
| `05-danmaku.gif` | 10 秒左右的动图：弹幕飘过 + 状态文案轮换 | ⭐ 强烈建议（价值最高） |
| `06-title.png` | 浏览器标签页标题轮换（可选） | 可选 |

## 要求

- **宽度 ≥ 1200px**（2x 屏截出来更清晰）；整窗口截图比裁切好，但别把无关的桌面内容截进去；
- **深色主题**（默认）最出效果；
- ⚠️ **不要包含任何私人聊天内容**：建议新开一个会话随便聊两句再截，或者用空会话；
- PNG / GIF 都行，单张控制在 2MB 以内（README 和市场的加载速度）。
